# JoyStrum guitar practice guide

[JoyStrum](https://joystrum.com/) is a browser-based guitar reference covering chord diagrams, fretboard notes, scale references and capo transposition. This public guide is maintained by the creator and contains no private application source.

## Read a chord diagram before playing

1. Identify the string order and fret numbers. Do not assume every diagram uses the same orientation.
2. An open-string marker means play the string without fretting it. A muted marker means leave that string out.
3. Place one finger at a time, then check each intended string separately.
4. Only strum the chord after all required strings sound clearly. A diagram cannot diagnose hand tension or posture.

## A short C-major exercise

Use the [guitar reference](https://joystrum.com/) to compare a C-major chord with its notes C, E and G. Locate those note names on the fretboard, then notice that the same pitch class can appear in several positions. Write down string and fret together so that your practice note identifies a specific position.

## Capo transposition, step by step

A capo raises the pitch of an open chord shape by one semitone per fret. For example, a C shape with a capo at fret 2 sounds as D major. Keep the chord shape you finger separate from the sounding chord name. Use JoyStrum’s capo chart to check the result before choosing a shape for a song.

## Limitations

References support practice but do not replace instrument tuning, listening or instruction. Confirm tuning and diagram orientation before comparing positions.
